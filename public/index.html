How it works

The same three steps, every time

  1. 1

    Update staging

    Plugins and themes update on a private copy of your site. Your live site isn’t touched.

  2. 2

    Check the pages

    It screenshots your key pages before and after, and compares them. If something breaks, it rolls back on its own.

  3. 3

    Go live only if it passes

    When every page checks out, the same updates go to your live site. If not, nothing changes there.

The check

See exactly what changed

Each key page is photographed before and after the update. If they match and the page still works, it gets a Pass.
